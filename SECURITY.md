# Security Policy

## Supported Versions

Security updates are provided for the latest published version.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through [this form](https://github.com/kemats/windbg-uiext-ghcp/security/advisories/new) or the **Security** tab of the GitHub repository by selecting **Report a vulnerability**. Do not include vulnerability details in a public GitHub issue because it may expose sensitive information before a fix is available.

Include the affected version, reproduction steps, expected and actual behavior, and any known impact. Do not include personal or confidential information in samples, logs, and screenshots before submitting them.

This is a personal, independently maintained project. Security reports are reviewed on a best-effort basis.

No response, investigation, fix, release, or disclosure timeline is guaranteed. Submitting a report does not guarantee that it will be accepted as a vulnerability or that a fix or mitigation will be provided.

A report may be declined if it is outside the project's scope, cannot be reproduced, or does not present a practical security risk in the supported usage model.

For ordinary bugs, use the [public issue tracker](https://github.com/kemats/windbg-uiext-ghcp/issues).
